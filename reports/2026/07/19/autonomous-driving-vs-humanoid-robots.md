# 自动驾驶与人形机器人：谁会更早大范围进入普通人的日常生活？

> 研究日期：2026年7月19日  
> 判断口径：至少一个主要市场连续24个月常态化运营，至少10%的城市人口每月至少一次直接使用，普通中等收入消费者能够以市场化价格持续使用，不依赖现场安全员，也不依赖随业务规模近似线性增长的高强度远程人工，并基本形成安全、保险、责任和监管闭环。

## 1. 执行摘要

以本文的“社会到来”定义衡量，限定区域L4 Robotaxi大概率先于家庭或公共服务人形机器人进入普通人的日常生活，排序置信度约75%。主要原因不是汽车更“智能”，而是驾驶任务可用地理围栏收敛，已有高频付费需求、成熟制造和服务体系，并已积累数亿无人驾驶英里或公里的真实暴露。工业口径下则不存在单一赢家。

## 2. 问题校准

### 2.1 两类技术都不是单一产品

自动驾驶至少包括：

- L2/L2+辅助驾驶：已经大规模普及，但驾驶员始终负责；
- L3有条件自动驾驶：只在限定道路、车速和环境下由系统承担动态驾驶；
- 限定区域L4：港口、矿区、园区或地理围栏城市区域；
- Robotaxi：面向公众的无人出租车；
- 无人配送和无人干线物流；
- 面向普通消费者的私人L4汽车。

人形机器人至少包括：

- 依赖遥操作或频繁后台接管的机器人；
- 工厂、仓库中的单任务人形机器人；
- 酒店、商场和医院服务机器人；
- 医疗和养老辅助机器人；
- 家庭单任务机器人；
- 能完成多种家务和照护任务的通用家庭人形机器人。

【事实】中国2026年新乘用车组合驾驶辅助渗透率约70%、NOA超过30%，但工信部同时强调这些仍属于L2、驾驶员承担责任。因此，辅助驾驶普及不能证明无人驾驶已经社会到来。[工信部，2026-07-02](https://www.miit.gov.cn/jgsj/zbys/qcgy/art/2026/art_7bcb480b0db5432f8542157a9fc12841.html)

### 2.2 五个阶段不能互换

1. 技术演示：一次或少量成功视频；
2. 小规模试点：限定人员、路线、时段，失败可由后台兜底；
3. 受控场景商用：真实付费，但场景狭窄；
4. 可持续规模化商业：收入增长快于人工后台和维护成本；
5. 普通人日常使用：达到本文的社会到来标准。

“签约—名义产能—生产—交付—投入工作—产生有效劳动小时—盈利”是七个不同事件。Robotaxi的“测试里程—载客里程—付费订单—独立用户—人口渗透率”同样不能互换。

### 2.3 A/B/C操作化定义

- A 技术到来：真实环境中持续产生经济价值，可靠性明显高于演示，且不依赖大量隐藏人工。
- B 商业到来：主要市场存在稳定付费需求，完全成本可持续，人工支持随规模次线性增长。
- C 社会到来：采用本文开头的24个月、10%城市人口月用、中等收入可负担、无现场安全员、无近线性后台人工及监管责任闭环标准。

### 2.4 是否属于虚假二分

如果把矿区无人车、工业人形、Robotaxi、私人L4和家庭机器人混在一起比较，这确实是虚假二分；不同场景会交替领先。但在“直接、大范围、常态化进入普通人生活”的主要口径下，可以得出有方向的判断：最接近门槛的是限定区域L4 Robotaxi，而不是工业机器人、L2汽车或家庭机器人样机。

### 3.3 同口径比较

| 维度 | 限定区域L4/Robotaxi | 全尺寸人形机器人 | 判断 |
|---|---|---|---|
| 真实环境暴露量 | 数千万订单、数亿无人英里或公里 | 单项目千小时、十万次料箱；全球有效劳动小时未知 | 自动驾驶领先约2—3个证据等级 |
| 付费客户 | 已存在公众订单和明确收入 | 少数工厂RaaS及企业销售；家庭无已验证交付 | 自动驾驶领先 |
| 远程人工 | 部分企业披露1:30—1:40量级 | 多数不披露；1X明确保留远程专家 | 自动驾驶透明度稍高 |
| 安全统计 | 至少Waymo有大样本、匹配基准和同行评议 | 无统一暴露小时、伤害率和近失事故基准 | 自动驾驶明显领先 |
| 单位经济性 | 个别城市运营口径声称盈亏平衡；企业总体仍亏损 | RaaS定价和BOM多为预测；厂商总体亏损 | 两者均未充分证明，自动驾驶更接近 |
| 制造规模 | 基于每年数千万辆汽车的成熟链条 | 公开生产以数百至低千台为主 | 自动驾驶基础制造领先 |
| 直接消费者产品 | Robotaxi已公开服务；私人L4尚无 | 家庭机器人主要是预订和内测 | Robotaxi领先 |
| 10%人口、24个月 | 城市级独立月活未公开，无法证明 | 明显未达到 | 两者均未满足C |

当前状态：

- 自动驾驶：限定区域Robotaxi已达到A；部分城市接近B，但完全成本证据不足；C尚不能由公开数据证明。
- 人形机器人：工厂单任务已达到狭义A；B只在少数工作单元萌芽；面向普通生活的A/B/C均未达到。
- 【未知】旧金山或武汉可能已经接近10%月度人口使用，但订单不能替代独立月活用户，且仍缺少连续24个月、市场化定价和完全成本证据。

## 4. 场景对照

以下时间均为【预测】基准窗口，而非企业目标日期。

| 对照场景 | 自动驾驶A/B/C | 人形机器人A/B/C | 领先方与原因 | 置信度 |
|---|---|---|---|---|
| 园区、港口、矿区 vs 工厂、仓库 | 自动驾驶A、部分B已到 | 单任务A已到，B预计2026—2031 | 当前自动驾驶领先；人形可能凭低速、隔离环境追近 | 70% |
| Robotaxi、无人配送 vs 酒店、医院、养老服务 | Robotaxi A已到，B约2026—2030，C约2028—2034 | 服务人形A约2028—2033，B约2030—2037，C大概率2036年后 | 自动驾驶明显领先 | 80% |
| 私人L4汽车 vs 多任务家庭人形机器人 | A约2030—2036，B约2033—2040，C约2038年后 | A约2029—2036，B约2034—2042，C更可能在2040年后 | 自动驾驶小幅领先，但两者都可能长期受阻 | 60% |

如果把“自动驾驶”限定为私人L4，优势明显缩小；如果允许Robotaxi代表直接进入生活，它已经拥有家庭人形机器人尚未拥有的公众使用、安全暴露和付费需求。若把“到来”改为工厂开始付费采用，人形机器人可能比私人L4更早，结论会反转，但这不是本文主要口径。

## 5. 因果结构

### 5.1 自动驾驶

AI感知、预测与规划 → 在限定ODD内处理道路和交通参与者 → 无人里程与任务完成率提高 → 尾部事故风险降低 → 远程协助和道路救援减少 → 每车有效运营小时、订单密度上升 → 单订单完全成本下降 → 许可、保险和责任机制形成 → 用户信任和复购提高 → 车队扩张 → 获得更多真实长尾数据。

正反馈是订单密度越高，折旧、清洁、充电、地图和后台成本越容易摊薄；负反馈是规模越大，遇到低概率长尾和重大事故的绝对次数越多，一次严重事故可能触发跨城市监管收紧。

### 5.2 人形机器人

视觉—语言—动作模型、模仿学习和遥操作数据 → 行走、抓取、工具使用与任务切换 → 每小时任务成功率提高 → 连续可靠运行和安全协作 → 远程接管、现场工程师和数据标注减少 → 有效劳动小时增加 → 每有效任务成本低于人力或专用自动化 → 企业复购或家庭留存 → 量产和维修网络扩张 → 更多真实任务数据。

工厂可以提供重复任务、可标注数据、维护人员和明确ROI；但任务种类扩大时，失败表面积、工具组合、家庭差异、机械磨损和安全责任也会同时扩大。

### 5.3 必要条件、促进因素与被高估变量

| 变量 | 性质 | 说明 |
|---|---|---|
| 长期安全任务完成 | 必要条件 | 没有它不能进入公共道路或家庭物理空间 |
| 人工支持次线性增长 | 必要条件 | 否则只是把司机或家政人员搬到后台 |
| 完全成本低于替代方案 | 商业必要条件 | 低硬件价格本身不充分 |
| 监管、保险、责任闭环 | 社会到来的必要条件 | 技术达标不自动获得合法规模 |
| 高订单或预订 | 促进因素，非充分条件 | 可能由补贴、押金或营销驱动 |
| 制造产能 | 促进因素，非充分条件 | 产能不等于良率、交付、使用和复购 |
| 模型参数、算力、演示视频 | 常被高估 | 不能直接解决磨损、热管理、维修和责任 |
| 地理围栏、固定工作单元 | 强促进因素 | 主动缩小问题，而非解决完整开放世界 |
| 专用机器人竞争 | 人形机器人的结构性限制 | 大量任务未必要求双足双臂 |

两者最难的短板都不是“再增加一些算力”。自动驾驶无法仅靠模型解决跨辖区责任、事故政治风险和车队运维；人形机器人无法仅靠模型解决机械寿命、接触安全、现场维修和家庭隐私。人形机器人的最短板更难，因为开放任务泛化、机械可靠性、物理安全、隐私和低成本必须同时成立。

## 6. 制造与单位经济性

| 项目 | 自动驾驶 | 人形机器人 |
|---|---|---|
| 核心供应链 | 汽车、电池、制动转向、传感器和服务体系成熟 | 执行器、灵巧手、力矩传感器和高柔性线束仍快速迭代 |
| 零部件 | 整车绝对零件多，但体系标准化 | 数量未必更多，却有几十个高精度主动关节；公开可比BOM不足 |
| 制造规模 | 中国2025年汽车产量3,453万辆 | 头部全尺寸人形厂商披露量仍以数百至低千台为主 |
| 良率 | 基础汽车良率成熟；自动驾驶套件仍需验证 | Figure 03最终装配一次通过率刚超过80% |
| 折旧与寿命 | 汽车寿命、残值和维修体系成熟 | 跌倒、碰撞、关节和手部磨损可能加速折旧 |
| 能源 | 主要由车辆移动决定，自动驾驶计算为增量负荷 | 双足平衡、频繁启停和手臂运动限制连续工作 |
| 维护 | 现有维修网可复用，但传感器校准、清洁和道路救援新增 | 缺少大规模服务网，大量关节增加故障点 |
| 利用率 | 出租车式车辆可每天服务多名用户 | 工厂可高利用；家庭需求零散、闲置率可能较高 |
| 隐藏人工 | 远程协助、清洁、调度和救援 | 遥操作、任务标注、现场集成和维修 |
| 规模学习 | 车队数据和成熟整车采购形成飞轮 | BOM百分比可能降得更快，但维修和接管会吞噬降本 |

【事实】中国2025年汽车产量约3,453万辆，显示现有整车供应链的量级优势。[中国汽车工业协会](https://www.caam.org.cn/chn/3/cate_38/con_5236999.html)

【事实】Agility向投资者给出的Digit v4约12.5万美元BOM、五年收入和成本模型属于示意性预测，并非已审计规模经营结果。[Agility SEC材料，2026-06](https://www.sec.gov/Archives/edgar/data/2074973/000121390026071287/ea029548401ex99-2.htm)

结论如下：

1. 在单一工厂工作单元中，某个人形RaaS项目可能先产生客户ROI；在可重复、面向公众、厂商整体可持续的口径下，Robotaxi更可能先形成正单位经济性。
2. 人形机器人BOM可能从高基数下降得更快，但自动驾驶更可能更早实现完全服务成本下降。
3. 人形机器人更容易被维修和后台人工反噬，因为其动作自由度、工具组合和任务种类更多。
4. 汽车产业链既是优势也是约束：它提供制造、金融、维修和需求，也带来混合交通、旧基础设施和多辖区监管。
5. 工厂可为人形提供数据、集成和零部件飞轮，但不能保证工厂能力外推到拥挤家庭。
6. 人形外形对楼梯、门把手和人类工具有兼容优势，但对清洁、配送、割草和搬运并非经济必要。2024年全球消费服务机器人接近2,000万台，主要仍是非人形清洁和庭院设备。[IFR服务机器人数据](https://ifr.org/news/service-robots-see-global-growth-boom/)

## 7. 人性、组织、监管与群体行为

- 便利和价格：Robotaxi与现有打车需求同构；家庭机器人必须证明节省的家务时间值每月数百美元。
- 事故容忍度：机器事故容易被视为系统性缺陷，人类事故常被视为个体事件。AAA 2025年美国调查中仅13%受访者信任乘坐自动驾驶车辆，约六成表示害怕。[AAA，2025-02-25](https://newsroom.aaa.com/2025/02/aaa-fear-in-self-driving-vehicles-persists/)
- 控制权和现状偏好：Robotaxi普及不要求消费者放弃私家车；社会到来只需高频使用。
- 家庭心理边界：持续看、听、移动和抓取的机器人会接触儿童、老人、药品、钥匙和家庭谈话，隐私门槛高于道路车辆。
- 照护信任：人们较容易接受搬运、提醒和监测，未必愿意把扶抱、喂药和儿童照护责任交给机器人。感知收益、隐私风险和信任是家庭社交机器人采用的主要变量。[Journal of Retailing and Consumer Services，2025](https://ideas.repec.org/a/eee/joreco/v82y2025ics0969698924003710.html)
- 劳动替代阻力：出租车司机、工会和地方就业部门可能反对Robotaxi；制造企业较容易在危险、重复和招聘困难工位中把机器人定义为补充劳动力。
- 企业叙事激励：预订、框架订单、产能和演示视频有融资价值，企业有动力先公布最好看的指标，而不公布MTBF、接管分钟和完全成本。
- 监管激励：批准技术的收益分散，严重事故责任集中，因此监管者要求比普通消费者更完整的安全案例。
- 保险激励：只有当暴露量、责任主体和事故分布可定价时，保险体系才会降低成本。
- 非线性事故：Cruise在2023年事故后被加州暂停许可，证明行业轨迹可能因单一事件离散变化。[California DMV](https://www.dmv.ca.gov/portal/news-and-media/dmv-statement-on-cruise-llc-suspension/)；[NHTSA处罚](https://www.nhtsa.gov/press-releases/consent-order-cruise-crash-reporting)

## 8. 竞争性解释

### H1：自动驾驶更早到来

H1可以解释Waymo和Apollo Go为何已经形成每周数十万量级无人订单：驾驶是高频、结果明确、付费体系成熟的任务，地理围栏又能主动排除部分天气、道路和法规长尾。

它解释不了为什么十余年投入后仍只覆盖少数城市、Waymo等为何不披露完整单位经济性、私人L4为何尚未出售，以及公众信任为何仍低。

H1依赖三个关键假设：新城市扩展不需要近乎重新开发；远程支持和车队运维随规模次线性增长；不发生导致多地冻结的重大事故。

证伪事件包括：

- 未来三年车队和城市数增长，但每车付费订单不升反降；
- 成熟城市在每日20单以上仍不能实现完全成本盈亏平衡；
- 监管重新普遍要求配备车内安全员。

### H2：人形机器人更早到来

H2的最强版本是：低速工厂和家庭任务失败的社会代价通常低于高速交通事故；VLA模型、模仿学习和遥操作数据可能带来跨任务跃迁；中国供应链可能迅速降低执行器和整机成本；工厂同时提供任务、数据、维修和制造飞轮。

它能解释Figure、Digit和优必选已经进入真实工厂，也能解释1X等家庭产品为何出现明确价格和预订。

它无法解释真实MTBF、成功率和接管比例为何几乎不公开，家庭产品为何仍需远程专家，已售设备数量为何远高于公开的连续有效劳动小时，以及专用机器人为何已经规模化、通用人形却仍未形成稳定市场。

H2依赖：模型泛化速度超过机械磨损和安全验证复杂度；同一硬件跨任务仍能获得高利用率；后台操作从训练手段迅速变成低频例外。

证伪事件包括：

- 到2030年主流设备仍不能在无频繁维修下累计2,000个以上有效劳动小时；
- 远程操作仍是一人支持数台，而不是数十台；
- 多数企业最终改用轮式或专用机械结构完成经济任务。

### H3：不存在单一赢家

H3对当前事实的解释力最高：非人形工业和家庭专用机器人早已规模化；园区和城市Robotaxi领先于公共服务人形；工厂人形可能早于私人L4；私人L4和通用家庭机器人都可能长期落后。

但是，如果必须回答谁先直接大范围进入普通人生活，H3仍不否定Robotaxi领先。

### 最强反方

最强反方不是“人形机器人已经胜出”，而是：人形机器人可能在2028—2032年因基础模型泛化、低成本执行器和廉价遥操作突然跨过可用门槛；Robotaxi却可能因一次重大事故、逐城审批和重资产运营长期停留在少数地理围栏内。

这个反方真实且不可忽视，但当前支持它的主要证据仍是产能、预订、早期工厂成绩和技术进步速度；支持Robotaxi的则包括已经完成的公众订单、无安全员道路暴露和安全结果。因此，在主要口径下，H1证据更强。

## 9. 历史规律与地区差异

### 9.1 历史规律

- 工业机器人：固定工作单元成功几十年，仍没有自然演化成家庭通用机器人，说明封闭场景成绩不能直接外推到开放生活。
- 电梯、航空和医疗自动化：高错误成本系统通常在技术可用后，还需要多年建立冗余、维护、认证、事故调查和保险体系。
- 智能手机和互联网：错误通常可逆，复制边际成本接近零，不是安全关键硬件扩散的合适速度基准。
- 汽车和新能源汽车：既有道路、供应链和金融体系能加速扩散，但车队替换、基础设施和法规调整仍以多年计。
- 家用电器：成功产品通常围绕单一清晰任务形成高可靠、低维护价值，这更支持洗衣机和扫地机式专用设备，而不是直接支持通用人形。
- 技术扩散并非平滑曲线：模型突破和良率提升可能突然加速，重大事故、供应链故障和责任诉讼也会突然减速。

【推断】高可靠硬件从“能工作”到“普通人持续愿意付费”通常不是一个模型代际，而是若干轮产品、服务网络和监管循环。商业可行到10%社会渗透也往往还需要3—10年以上。

### 9.2 地区差异

| 地区 | 自动驾驶 | 人形机器人 | 谁可能先直接进入生活 |
|---|---|---|---|
| 中国 | 制造和传感器成本低、政府支持强、城市密度利于高订单；但较低人力成本压缩节省空间，私人L3/L4准入谨慎 | 供应链、地方政策和产量领先；工厂数据飞轮强，家庭支付能力和服务工资构成约束 | Robotaxi更可能先；工业人形部署可能全球领先 |
| 美国 | Waymo已有最大规模之一的公开无人服务；高工资支持商业化，但州际监管碎片化、诉讼和公众信任风险高 | 基础模型、资本和头部企业强；家庭面积大，但服务网和产品责任昂贵 | Robotaxi更可能先 |
| 欧洲 | Mercedes L3和型式批准体系成熟，但公共L4部署慢，隐私和安全审查严格 | 高工资、老龄化产生需求；机械法规、AI高风险规则和隐私要求提高合规门槛 | 两者都较慢；工业人形可能早于家庭 |

欧盟已经建立限定区域ADS型式批准框架，但实际运营仍受成员国规则约束。[EU Regulation 2022/1426](https://eur-lex.europa.eu/legal-content/EN/TXT/?uri=celex%3A32022R1426)；人形机器人还需满足机械安全法规，若作为安全组件或医疗设备则可能进入AI高风险监管。[EU Machinery Regulation](https://eur-lex.europa.eu/eli/reg/2023/1230/en)；[EU AI Act](https://eur-lex.europa.eu/eli/reg/2024/1689/oj/eng)

【推断】技术最先进的国家未必最先普及。人口密度、出租车价格、地方许可和制造成本可能比模型排行榜更关键。中国可能在工业人形产量领先，却因家政劳动力价格较低而在家庭普及上落后于高收入市场。

## 11. 敏感性分析

### 11.1 人口阈值

| “大范围”阈值 | 结论 |
|---|---|
| 1%人口月用 | Robotaxi在部分城市可能已达到或非常接近；人形未达到，自动驾驶优势最大 |
| 5% | Robotaxi大概率在2027—2030年先达到 |
| 10% | 本文主口径，自动驾驶领先 |
| 20% | 两者都推迟，Robotaxi仍领先但时间差可能缩小 |

由于企业不披露一致的城市独立月活，不能用订单量直接宣布某城市已经跨过1%、5%或10%。

### 11.2 到来对象

- 工业规模化：传统非人形机器人早已到来；全尺寸人形与园区无人车并行，不存在单一赢家。
- 公共商业服务：Robotaxi明显领先。
- 普通家庭常态使用：若比较私人L4与通用家庭人形，自动驾驶只小幅领先，置信度约60%。
- 若把任何L2辅助驾驶算作自动驾驶：答案已在多年前结束，但这是定义偷换。

### 11.3 变量冲击

| 变量变化 | 对顺序的影响 |
|---|---|
| AI能力整体加速 | 两者受益；人形因现有能力缺口更大，可能缩小差距 |
| 驾驶长尾快速解决 | 显著提高自动驾驶先到概率 |
| 后台人工成本上升 | 两者受损；人形若接管更频繁，受损更大 |
| 机器人硬件价格下降 | 只有可靠性同时改善才可能反转 |
| 人形量产良率提高 | 缩小差距，但不直接解决有效劳动小时 |
| 劳动力成本上升 | 同时利好两者，更利好高利用工业场景 |
| 电池和能源进步 | 中等影响，通常不改变顺序 |
| 严重Robotaxi事故 | 可能通过监管非线性提高人形先到概率 |
| 自动驾驶监管放松 | 强化自动驾驶领先 |
| 机器人产品责任收紧 | 推迟家庭人形 |
| 保险责任体系成熟 | 对自动驾驶的边际帮助更大 |
| 家庭支付意愿提高 | 提高人形概率，但可靠性仍是前置条件 |
| 家庭隐私信任下降 | 显著推迟人形 |
| 专用机器人竞争加强 | 降低人形形态本身的需求 |
| 遥操作长期存在 | 一人支持少数机器人不满足C；一人支持50—100台且仅偶发介入可以接受 |

最敏感的三个变量是：

1. 人形机器人每有效劳动小时所需的遥操作和维修时间；
2. Robotaxi发生严重事故后的监管反应强度；
3. 机器人跨家庭多任务泛化能否转化为数千小时可靠运行。

最可能使结论反转的单一变量，是人形机器人的“可靠劳动/人工支持比”出现非连续跃迁：在家庭多任务中做到一名后台人员支持50—100台、连续数千小时运行、完全成本接近当地家政工资。

看似重要但通常不改变顺序的变量包括单次模型榜单、机器人标价、纯电池能量密度和名义产能；它们不能单独解决可靠性、人工支持与责任闭环。

## 12. 红队压力测试

| 可能推翻结论的问题 | 当前最佳答案 |
|---|---|
| 结论最依赖哪个未验证假设？ | Robotaxi扩展到新城市时，远程支持、地图和运维不会近线性增长。该假设仅有局部公司数据支持。 |
| 是否选择了有利于自动驾驶的定义？ | 若以Robotaxi对比家庭人形，确实不是私人产品对私人产品；因此本文另行比较私人L4与家庭机器人，自动驾驶优势降到60%。主口径仍合理，因为公共服务也是直接生活。 |
| 是否把订单当成10%人口？ | 没有。订单会重复，缺少城市独立月活，因此C尚未公开证明。 |
| 是否把演示、订单或生产当成人形部署？ | 没有。Figure的350台、优必选1,079台、1X一万预订分别标为生产、销售和预订，未当作有效劳动。 |
| 是否忽略隐藏人工？ | 没有，但数据不足。人形机器人的接管分钟和现场工程时数尤其缺失。 |
| Waymo安全数据是否有利益冲突？ | 有。其样本大、方法较好，但由公司和关联研究者生成，只能证明特定ODD，不能外推所有企业和私人L4。 |
| 是否线性外推？ | 没有。概率情景显式保留模型跃迁和事故监管两种相反的非线性事件。 |
| 是否存在地域偏差？ | 有一定风险。中美数据最多，因此“全球”定义为至少一个主要市场，而不是全球人口同时普及。 |
| 最强相反证据是什么？ | 人形模型进步快、中国制造降本快、早期工厂部署和家庭预订已经出现；但缺少可审计的连续劳动、接管和留存数据。 |
| 缺少的决定性数据是什么？ | 双方统一披露的“每1,000服务小时人工干预分钟、维修小时、严重伤害事件和完全成本”。 |

三项足以迫使修改结论的未来事实：

1. 至少1万台家庭人形机器人连续24个月付费使用，年留存超过70%，并完成多种家务；
2. 独立审计证明其每台每年产生2,000小时以上有效劳动，远程支持低于每50台一名人员，完全成本接近普通家政工资；
3. Robotaxi在中美主要市场因重大事故、单位经济性失败或重新要求现场安全员而连续三年停止扩张。

压力测试后，排序信心由约80%下调至75%，但结论方向不变。

## 14. 最终结论

当前最可能的答案是：限定区域L4 Robotaxi所代表的自动驾驶会先于公共服务和家庭人形机器人，大范围、常态化进入普通人的直接生活。

决定顺序的三个根本变量是：

1. 问题能否被收敛：Robotaxi可以用城市、道路、天气和时段定义ODD；家庭任务难以彻底地理围栏化；
2. 可靠劳动与人工支持之比：自动驾驶已有数亿无人里程和次线性后台支持的初步证据；人形对应数据严重缺失；
3. 既有商业和制度基础：出行需求、道路、车辆制造、支付、保险和维修已经存在；家庭人形还需建立产品类别、服务网络和责任制度。

公众最容易误判的地方是：把L2辅助驾驶的高渗透当成无人驾驶，把人形机器人的演示、订单和生产量当作有效劳动，以及认为AI模型一旦足够聪明，机械寿命、维修、隐私、保险和责任就会自动解决。

本结论适用于直接生活、10%城市人口月用和24个月持续运营的口径。若改成工厂单任务部署，人形机器人可能早于私人L4；若改成任意辅助驾驶或非人形家电，则相应技术早已到来。

最终排序置信度为75%，具体到来年份置信度仅为中低。结论最可能被“家庭人形可靠劳动/人工支持比发生数量级跃迁，同时Robotaxi遭遇重大事故和跨市场监管冻结”推翻。
